# ✈️ Airline Manager Data Intelligence System

## 📌 Overview
This project extracts and analyzes data from a mobile airline simulation game using OCR and Python.

It demonstrates how to build a real-world data pipeline from unconventional data sources.

## ⚙️ Pipeline
Screenshot → OCR → Data Cleaning → Storage → Analysis

## 🧰 Tools Used
- Python
- Pytesseract (OCR)
- Pandas
- Matplotlib

## 📊 Key Features
- Automated screenshot data extraction
- Structured dataset creation
- Trend analysis and visualization

## 🚀 Future Improvements
- Real-time dashboard
- Machine learning predictions
- Route optimization analytics
